Privacy policy

Last updated 30 September 2026

This is a personal, self-hosted instance of Inbox Zero. Its only user is its owner (ilkoi338@gmail.com).

What it accesses

With the user's permission it reads, labels, archives and drafts emails and manages Gmail filters in the connected Gmail account, using Google's Gmail API.

Where data is kept

Account tokens (encrypted) and the data needed to run rules are stored in a private database on Railway that only the owner controls.

Who it is shared with

Email content is sent to an AI model through OpenRouter only to classify and draft emails. Data is not sold, not used for advertising, and not shared with anyone else.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Access can be revoked at any time at myaccount.google.com/permissions; stored data is deleted when the instance is removed.
